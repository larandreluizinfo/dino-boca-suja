# 🦖 DINO BOCA SUJA 🤬

O dinossauro do Google que xinga em inglês, francês e italiano a cada pulo.

▶️ Jogue online (GitHub Pages): URL aparece aqui após ativar o Pages.

## Jogar local
Abra `index.html` no navegador, ou:
```powershell
npx serve .
```

## Controles
- Espaço / ↑ / clique / toque = pular + xingar
- ↓ = agachar (desvia do ptero baixo vermelho!)
- P = pausa • M = muta voz
